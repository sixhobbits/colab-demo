# colab-demo

A demo of a runnable cookbook notebook that opens in Google Colab and runs without an API key.

| Cookbook | Open |
| --- | --- |
| Re-ranking retrieval results | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/sixhobbits/colab-demo/blob/main/cookbooks/rerank_typesafe/rerank_typesafe.ipynb) |

The notebook downloads its saved API answers from
[typesafe-public-examples](https://github.com/typesafe-ai/typesafe-public-examples/tree/main/cookbooks/rerank_typesafe)
and replays them, so *Run all* makes no API calls.
